Pilot Rhyme Expedition — Director and Pilot seats that share one world

Multi-agent work often needs one agent that holds the map and others that run local steps. Pilot Rhyme makes that Director/Pilot structure a reusable pattern: store the roles once, keep each mission as only what differs, and let everyone write into one shared world.

Abstract

We compared five arms on 100 six-hop missions with differing wording: flat peers, shared text without roles, Director/Pilot with private copies, Director/Pilot with an exact-text cache, and Director/Pilot with Pilot Rhyme (role template once + shared world + per-mission deltas). Flat peers and shared text recovered 0 of 100. All three Director/Pilot arms recovered 100 of 100. The exact-text cache hit zero times. Pilot Rhyme stored the work 22% smaller than the exact-text cache and 80% smaller than private Director/Pilot copies.

Primary research question

Does a Director/Pilot role rhyme outperform flat peers on coordination, and beat an exact-text role cache on store size when mission wording differs?
