What “held-out partner” means

A held-out partner is the hidden answer to “who goes with this row?” We measure the strongest long-range coupling for a query object, then we do not print that id as a labeled solution in the prompt. Scoring checks whether the reader still names it. Kitchen example: planet A’s hidden partner is planet Q — LINEAR/FLAT/AWARE packs either help the reader name Q or they do not.

Abstract

E9–E11 showed that packing proteins, knowledge passages, and macro series as LINEAR / FLAT / AWARE language changes partner recovery. Cosmic Rhyme hitchhiked that arm as C5; this expedition owns it and adds a human-genome demonstration. Default scoring needs no API key.
