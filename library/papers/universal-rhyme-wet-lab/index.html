Abstract

Modern computing architecture assumes computation is performed by discrete electronic processors. An alternative possibility is that computation can be physically distributed into the electromagnetic medium through which information propagates. This paper examines whether existing wet-lab experimental evidence is sufficient to establish that physical premise.

The claim is not that one laboratory has built a data center out of electromagnetic waves. The claim is that independently demonstrated physical capabilities form a connected experimental chain:

interference → cavity Fourier → programmable matrix → metasurface Fourier/convolution → RF machine-learning inference.

Working form

Different embodiment. Same computational organization.

A computational operation does not require the physical architecture in which it was historically implemented. When the relational transformation can be preserved, computation can migrate between physical representations.

What this proves / does not prove

Proves: Physical EM systems can perform useful mathematical and ML computations without first converting every operation into conventional digital processor execution. Data center ≠ computation; GPU ≠ computation — they are implementations.

Does not prove: Hyperscale GPU replacement for every AI workload; elimination of all data centers; arbitrary general-purpose free-space RF computing; equal memory/programmability/cost at hyperscale.
