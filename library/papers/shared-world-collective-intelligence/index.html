Rhyming vs Non-Rhyming World Models

Prior expeditions already showed that a rhyming shared world between agents produces measurable gains. This expedition asks the next question: where does a rhyming world model beat a non-rhyming one, on real data and on open-source world models we ran ourselves?

On the protein task a plain shared notebook also got every answer right, so there the gain is size, not accuracy. Upstream DreamerV3 / MuZero / TD-MPC2 / V-JEPA 2 numbers describe minutes of training on a laptop-class CPU. TD-MPC2 is a partial reproduction.

Abstract

Real agent traffic is mostly the same job in different words. Exact-text caches and prefix reuse only help when bytes repeat. A rhyming world model recognizes the pattern. Across protein notes, moose GPS tracks, and agent messages, rhyme stored the traffic 33% to 49% smaller than an exact-match cache that never hit. With mostly identical text, the exact cache still wins, and FractiSI keeps it. On a same-model test with four agents that each see one piece of a balancing task, one shared world predicted what happens next 5× to 20× more accurately than private copies. Open-source world models (DreamerV3, MuZero, TD-MPC2, V-JEPA 2) ran for real on CPU; all are strong for one agent and none can share a world between agents.

Primary research question

Where do rhyming world models outperform non-rhyming ones — especially on high-value traffic with the same structure and different words — and how do they sit beside single-agent latent world models?
