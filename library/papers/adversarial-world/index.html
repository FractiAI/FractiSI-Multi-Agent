Abstract

Multi-agent collectives fail in a familiar way: an agent speaks, others echo, and the echo becomes “the world.” This Rhyming Expedition arm asks whether FractiSI’s shared-world discipline — no agent owns the world — can keep malicious computational agents from redefining canonical reality.

We reuse FractiSI concepts already present in Predictive Shared State (propose/commit/rollback) and the world-model expedition’s adversarial class, then build a computational security scoreboard. Seven models compete: naive overwrite, majority vote, trusted authority, FractiSI deltas, deltas+provenance, deltas+provenance+rhyme, and full Adversarial FractiSI (rhyme + authority bounds + quarantine + selective rollback).

Attacks A–J cover false observation, malicious delta, memory poisoning, false consensus, Sybil, rhyme manipulation, context manipulation, goal hijacking, privilege escalation, and slow poisoning. Epistemic scenarios demand minority truth, majority falsehood, legitimate disagreement, truth without rhyme, and novel truth.

On seed 20261120, fractisi_full and fractisi_rhyme containment = 1.000; majority = 0.400; naive = 0.100. Levels L1–L7 fire on computational criteria. Candidate Goldilocks rank favors relational rhyme over naive openness and over pure trusted monoculture. computational ≠ production security.

1. Question

When a multi-agent collective cannot trust every agent, can the shared world itself become the primary object of trust — maintained through evidence, relationships, provenance, bounded authority, and relational rhyme rather than blind trust in individuals?

Deeper: can the collective stay open to new information while keeping a coherent shared world that malicious agents cannot easily rewrite for everyone else?

2. Previously demonstrated / hypotheses / falsifiers

2.1 Previously demonstrated

  1. Shared-World Collective Intelligence: rhyming shared worlds beat exact caches under wording change.
  2. Predictive Shared State: unapproved predictions cannot overwrite authoritative world.
  3. World-model expedition adversarial class: majority/verifier computational correction path.

2.2 New hypotheses

  1. Agent claims remain hypotheses until relational consistency validates a delta.
  2. Relational rhyme distinguishes independent corroboration from Sybil/repeated assertion.
  3. Full Adversarial FractiSI beats majority/naive on computational attacks without crushing legitimate disagreement or novel first sightings.

2.3 Falsifiers

Majority ≥ FractiSI containment; rhyme raises false rejection of honest disagreement; manufactured fake rhymes defeat FractiSI; trusted authority dominates on both security and openness; truth-without-rhyme rejected as false.

6. Qualifications / failures recorded

  • computational simulated theater — not a CVE hunt, not a live red team.
  • fractisi_deltas / provenance fail computational containment without rhyme — reported honestly.
  • Trusted authority also contains; openness/novel claims from untrusted seats remain a tradeoff.
  • Context-manipulation computational still accepts true temperature when ground includes stress-test context; deeper contextual deception remains an open attack surface.
  • Selective rollback mechanism is present; strong rhyme quarantine often prevents need to roll back on this board.
  • Perfect computational containment is expected when attack markers and independence features are lab-controlled — scientific content is the gap vs majority/naive and the preservation of disagreement/novel unconfirmed.

7. Final questions (open)

  1. Can the shared world become the primary trust object under partial agent distrust?
  2. Can a collective stay open to new information while blocking malicious redefinition of reality?
  3. Does relational rhyme remain an advantage when attackers control real sensors rather than computational controllers?
