Upgrading the World Model

Shared-world coordination for human and digital agents. A six-experiment lab on real public data, and what it does and does not show.

Honesty boundary

Application companion expedition. Not ENGINE_SHELF. Not a live LLM bake-off, not production fleet benchmarking, and not organizational advice. Results are architectural and public-data signals from the FractiSI Computational Lab. Expedition 002 and Tiny Gateway figures are workstation receipts. The Goldilocks scorecard uses weights chosen by the lab and is a scoreboard, not a measured outcome.

Abstract

As agents become more capable, the limit shifts from what each agent can do to how the system organizes them. A linear model (agent, role, rule, plan, objective, hierarchy) works in stable, well-specified settings, but it duplicates context across agents, constrains discovery, and raises the cost of keeping agents in agreement. We test a shared-world alternative, the Fractal Holographic Goldilocks world model, in which agents hold deltas against one shared world and reconstruct selectively. On real public data and regenerable lab harnesses, shared-world configurations cut duplicated bytes by about 91% and selective sharing cut bytes by about 87%, each at matched accuracy. Temporal structure was detectable in real series, though not uniquely better than a bag-of-features baseline on macro forecasting.

Research question

Can a population of human and digital agents produce more useful collective capability, with less unnecessary risk, cost, and friction, by changing the world model through which it coordinates?

Two world models

Legacy Linear. Closed, hierarchical, rules and plans first. Information moves agent to agent and each agent keeps its own copy of the context. It is effective when objectives are fixed and costly when capable agents discover relationships the plan did not anticipate.

Fractal Holographic Goldilocks. One shared world, differentiated agents, relationships, boundaries, feedback, and consent. Each agent stores its delta and reconstructs what it needs. The design target is a band: enough structure for coherence and safety, enough freedom for agency, enough adaptability to be sustainable, and enough usability to be worth participating in.

Method

The suite runs six experiments from seed 20261115, regenerable with npm run research:synthobs-nvidia-goldilocks-awareness-expedition in the SING 13 repository, with receipts mirrored at research/nvidia-goldilocks-lab/data/.

  • E0. Expedition 002 and Tiny Gateway receipts, cited and regenerated.
  • E1. FRED UNRATE walk-forward (805 windows, 1959 to 2026): temporal model vs bag-of-features vs sequence-permuted control.
  • E2. Movebank animal tracks aligned with the Kp geomagnetic index (268 rows): chronological lag-1 structure vs shuffled null.
  • E3. Competition-first vs shared-world collaboration: accuracy and duplicated bytes.
  • E4. Closed vs open selective sharing: RMSE and bytes.
  • E5. Scorecard across four world models using the dimensions E0 to E4 measured.

Results

E0. Under the same budget, flat skimming solved 0 of 100 discovery boards and guided reconstruction solved 100 of 100, using about half the coordination rounds (6 to 3) and far fewer operations (40 to 6). Tiny Gateway aggregate stands at about 84.5%.

E1. Temporal RMSE was 5.675 against 6.115 for the permuted control, which confirms that time order carries signal. The bag-of-features baseline reached 5.673, effectively tied. On this series the temporal model is not uniquely better.

E2. Mean-step lag-1 correlation was about 0.342 chronologically against about 0.036 for the shuffled null. Spread showed no lag-1 structure.

E3. Accuracy was identical at 0.30 for both configurations, and the shared world cut duplicated bytes by 91.3%. The result shows efficiency at parity, not an accuracy gain.

E4. RMSE was effectively equal (6.847 closed, 6.848 open selective) and open selective sharing cut bytes by 87.3%.

E5. Goldilocks alignment scored 76.5, unbounded openness 75, competition-first 71, and control containment 66.5. The margin over unbounded openness is small and depends on the weighting.

Falsification

Reject or revise the approach if shared worlds give no advantage under matched budgets, if added autonomy degrades results, if consent-based coordination loses to central control, if accommodating differentiated agents adds nothing measurable, or if migration raises complexity without a safer, cheaper, more sustainable, or more usable system.

Applying it to an organization

For any organization building on accelerated computing, the first step is an audit. Map agent architecture, world representation, where context is duplicated, human and AI-agent density, boundary design, and flow bottlenecks. The aim is to locate where the world model in use constrains capability that is already present. Reorganization is not the first move.

Limits and next experiment

These are structured-state and public-data experiments. They do not show that LLM agents reason more accurately, converge faster, or deliver more useful work per dollar under FractiSI. The next decisive experiment holds models, prompts, tools, information, and budgets fixed and changes only the information architecture.
