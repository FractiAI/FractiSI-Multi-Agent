# Output

Everything the pipeline generates. Regenerate with `node scripts/run_pipeline.mjs`, or `--rebuild` to re-derive from existing receipts.

## Contents

| Path | What it is |
|---|---|
| [`data/`](data/README.md) | Receipts and derived data |
| [`figures/`](figures/README.md) | Rendered figures and their registry |
| [`manuscript/`](manuscript/README.md) | Hydrated sections, ready to render |
| [`pdf/`](pdf/README.md) | The rendered PDF |
| [`reports/`](reports/README.md) | What the template's validators and renderer recorded |
| [`web/`](web/README.md) | The manuscript as HTML |
