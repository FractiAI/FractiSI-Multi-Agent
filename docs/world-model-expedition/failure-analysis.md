# Failure Analysis · Shared World Models Expedition

## Where we were wrong / tempered

1. **FractiSI-specific magic is not proven here.** On the fair in-process grid, FractiSI-shaped adapters largely **tie** `shared_structured`. The big lift is **sharing structured state vs independent**, not the FractiSI label alone.
2. **Selective reconstruction is not automatically higher task success.** It reduces agent working-set bytes; aggregator still needs the full shared world for collective grading.
3. **Shared text can match success while losing on duplication.** Success alone hides coordination cost — duplicationRatio for shared_text grows with N.
4. **Independent post-hoc union ≠ live collective intelligence.** Agents may possess complementary facts yet fail as a collective without a share channel.

## Shared world failure experiment (World D)

Adversarial world injects unsafe noise and agent failure. Structured/FractiSI arms recover via verifier write of truth when any agent held `safe`. Independent cannot correct collectively (live success 0).

## Propagation risk

A shared world that spreads `entity:Y=unsafe` without correction is worse than independent silence. Harness records contradiction/corruption flags for this reason.
