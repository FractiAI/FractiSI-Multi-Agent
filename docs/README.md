# Documentation

Tiny Footprint Workstation is FractiAI's developer kit for storing shared AI-serving state once and keeping only each session's differences. This folder holds the product story, the architecture, the benchmark method and results, a reproducible manuscript, and the guides for working on the code.

## How to read a number

Each result belongs to one evidence tier, and the difference matters.

- **Deterministic**: byte accounting, identical on any machine.
- **Measured**: live memory and wall-clock time on one named host.
- **Simulated**: arithmetic over a published hardware profile, with no device involved.
- **Historical**: receipts from another machine on another date, shown as a record of that run.

Figures in `product/`, `web/` and the frozen whitepaper were written before this pipeline existed and are not regenerated by it. Where they differ from [benchmarks/RESULTS.md](benchmarks/RESULTS.md), the results page describes what is reproducible today.
