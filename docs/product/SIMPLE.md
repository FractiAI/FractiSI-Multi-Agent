> **Evidence note.** Byte counts on this page are serialized JSON, not memory. For live memory, latency and real-model results, see the [results and claim ledger](../benchmarks/RESULTS.md).

We deliver software installed **alongside** existing AI. Customers do not buy new computers, replace GPUs, or move operations to FractiAI.

1. **Local** — developer PC · Workstation Kit · Free / Pro  
2. **Enterprise** — company GPU servers · Server Edition · annual license  
3. **Cloud** — provider fleets · Platform Edition · negotiated agreement  

**Without:** each session may retain full shared context independently.  
**With:** one shared organization, plus the part that differs.

A rhyme matches the shape of a session, not the exact words. When forty sessions share that shape and say different things, the rhyme stores about 29 percent less than keeping every session or caching only identical text. When every session repeats the same sentence, a cache is smaller, because it keeps one copy and the rhyme still records each line.

We install the Tiny Footprint package (runtime, SDK, benchmarks). We integrate with the customer’s inference stack through versioned adapters—Workstation 0.1 ships the in-process demo adapter; serving integrations are planned. We do not require replacing that stack.

Sharing system/static context is the first integration. Transparent KV-cache changes need engine-specific engineering.
