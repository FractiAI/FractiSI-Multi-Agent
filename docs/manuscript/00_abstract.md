# Abstract {#sec:abstract}

Software that shares state across AI serving sessions promises less memory and lower latency by storing a common pattern once and keeping only each session's differences. The Tiny Footprint Workstation is one such kit. Its published evidence includes an aggregate reduction of {{HIST_AGGREGATE}} in representation bytes and device measurements from a laptop GPU. This study rebuilds that evidence as one reproducible pipeline with three tiers: byte accounting that is identical on any machine, live memory and latency measured on {{HOST_CPU}}, and real forward passes through {{LLM_MODEL_NAMES}}.

The published aggregate reproduces to every digit, at {{AGG_PUBLISHED}}. Whether it clears the {{TARGET}} gate depends on selection and weighting: it is {{AGG_UNWEIGHTED}} with equal weights, {{AGG_LOSSLESS}} over the lossless workloads, and {{AGG_NON_STRAWMAN}} once a baseline built as a deliberate anti-pattern is also removed. Serialized bytes overstate memory. For sessions sharing a system prompt, JSON predicts a reduction of {{HEAP_AI_TINY_JSON}} and the live V8 heap shows {{HEAP_AI_TINY}}, while a plain object reference reaches {{HEAP_AI_ALIASED}} with no engine. For sessions sharing only a shape, JSON predicts {{HEAP_RHYME_TINY_JSON}} and the shipped engine's heap shows {{HEAP_RHYME_TINY}}; a tighter encoding of the same idea reaches {{HEAP_RHYME_COMPACT}}, past plain references at {{HEAP_RHYME_ALIASED}}. Materializing one session takes {{LAT_AI_TINY_RATIO}} to {{LAT_RHYME_TINY_RATIO}} the duplicated store's time, falling to {{LAT_AI_NOCLONE_RATIO}} and {{LAT_RHYME_NOCLONE_RATIO}} without one cloning call. On real models, reusing a shared prefix speeds prefill by {{LLM_PREFILL_RANGE}}, with last-position logits within {{LLM_CONTROL_WORST_LOGIT}} of a full prefill on the model where a wrong cache is detectable, and leaves decode at {{LLM_DECODE_RANGE}}. Key-value residency falls {{KV_DEVICE_REDUCTION}} on the device allocator against {{KV_PREDICTED}} predicted, and {{KV_WITH_WEIGHTS}} once model weights are counted. A production prefix cache provides the same mechanism.

Two published figures do not survive as stated. The {{HIST_ALLOC}} GPU allocation reduction is arithmetic on requested buffer sizes and an assumed delta, and it reproduces with no GPU. The {{HIST_TRAIN}} training speedup becomes {{LLM_TRAIN_RANGE}} once the arms are warmed up and interleaved. This study also discloses and corrects a defect through which the kit reported a stored laptop receipt as a fresh result on hosts with no GPU. The evidence supports prefix sharing as a real, bounded memory optimization. It does not establish a reduction of {{TARGET}} in device memory for AI serving.

**Keywords:** AI serving; memory efficiency; key-value cache; prefix caching; benchmarking methodology; reproducible research.
