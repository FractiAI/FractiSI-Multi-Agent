# Expedition: Shared World Models for Collective Intelligence

Fair comparative benchmark. **Do not assume FractiSI wins.**

## Run

```bash
npm run research:world-model-expedition
# or
node experiments/world-model-expedition/scripts/run_expedition.mjs
```

## Outputs

- `results/raw/all_runs.jsonl` — every episode
- `results/summary.json` — aggregates + scientific conclusions
- `results/results.md` — human report
- `docs/world-model-expedition/` — architecture, landscape, design, final report

## Conditions

1. Independent agents  
2. Shared text context  
3. Shared structured state  
4. FractiSI shared world  
5. FractiSI + agent deltas  
6. FractiSI + selective reconstruction  

Genie / Cosmos / V-JEPA / Dreamer are marked **NOT EXECUTABLE** when not wired — scores are never fabricated.
