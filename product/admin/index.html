Workstation admin

Administrative status

The local admin surface for your Workstation. It reads session state from .fractisi/state.json, which exists after init.

Run it

The full path needs Git and VERCEL_TOKEN. Then run the command below.

node scripts/tiny.mjs try
node scripts/tiny.mjs status --json
