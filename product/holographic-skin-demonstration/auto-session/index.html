Auto Session

Two halves of your desk. You pick the pictures — or let activity pick them.

Not on phones or tablets yet

Auto Session needs a desktop computer with a split screen (your work app on one half, this skin on the other). Handheld devices are not supported yet.

You can still browse the Enrichment Menu on this device — open Play — but Manual / Autodetect desk session stays on desktop for now.

Open Enrichment Menu

Simple instructions

  1. Split your screen. Work on one half. Skin (browser) on the other.
  2. Other half = any app you choose — not only an IDE. Cursor, Slack, Mail, Chrome, a spreadsheet…
  3. Manual — tap a picture below; it stays until you pick another.
  4. Autodetect — select Autodetect and the page tries to start the desktop helper by itself. Pictures then follow which app is in front.

First time on a computer: run npm run skin:auto-session:install once in the FractiSI repo so Autodetect can auto-launch the helper. After that, choosing Autodetect is enough.

Autodetect

Selecting Autodetect asks this page to start the local helper automatically (fractisi-skin://). If the helper is not installed yet, install once, then try again.

npm run skin:auto-session:install

That registers auto-launch. Afterward, Autodetect starts the helper without you typing npm run skin:auto-session each time.
