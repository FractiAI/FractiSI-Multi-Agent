What the capacity buys

Measured in FractiSI labs against flat skim, full per-agent copies, gzip-only packs, and exact-text cache.

Lab results

Architectural and structured-state suites. Details are in the library.

Discovery 100 / 100 vs 0 / 100

Guided shared-world recovery finds chains and solutions that flat skim does not assemble under the same budget.

Convergence −50% rounds · −85% ops

Fewer propagation rounds and operations on the same constrained discovery path.

Density vs full copy 36× – 62×

The shared world is stored once. Each agent adds only its difference, so more agents fit in the same memory budget.

After gzip ~42%+

Compression shrinks copies. It does not remove the cross-copy cost FractiSI is built to avoid.

When wording differs Rhyme beats exact cache

Sessions with the same shape and different words favor rhyming templates over exact-text cache.

Tiny Gateway 84.5% · 81.4%

Representation and GPU-allocation reduction from the Tiny Footprint and Tiny Gateway core.

Get started

  • Community. Clone GitHub, install Node 18 or later, and run the Test Drive. Use GitHub for commits. Cloud deploy is not included.
  • Pro. More concurrent capacity and guided workflows on your machine.
  • Team and above. Governance and paid cloud deploy. Set a cloud token and FRACTISI_EDITION.
  • Enterprise and Cloud. A license and support to run FractiSI on infrastructure you already own or operate. We do not sell dedicated servers, cloud regions, or hosted GPU fleets.
