Tiny Footprint

Software installed alongside the AI you already run. It is not a new computer, and it is not a replacement for your stack.

We operate open source, with a freemium model. Community is free and needs no account. The kit is on GitHub. Developer Pro is a proposed paid step, $29–49 a month, for people who want it.

Tiny Footprint widens what a cache can bank. Exact prefix sharing—the part production caches already do—remains the big win when the same words repeat. Organizational rhyme adds the near-duplicate case exact caches miss: same shape, different wording. The aim is better utilization of the memory bank you already have, not a larger chip.

One engine, three places it can live

Local

For a developer on their own machine. Community is free. Developer Pro is proposed at $29–49 a month. The Workstation kit is the way in: an editor project, a demo, and benchmarks you run yourself.

Server

For a company GPU fleet that already serves models. Team and enterprise terms are proposed, from $199 a month to a custom annual license. Start on a test cluster.

Cloud

For platform operators. Licensing, OEM, and per-GPU-hour terms are negotiated. This is a partner conversation, not a self-serve checkout.

What the open benchmark study shows

Independent re-measurement (Apple M4 Pro · small GPT-2-family models · PR #3) is the honesty bar for product claims. Sharing a prompt prefix is the mechanism that performs; production prefix caches already do that for exact text. Prefill can run about 1.3×–3.5× faster and KV residency can fall about 84% (about 27% once weights are counted). The rhyming engine does not beat a plain object reference on live heap in that study. Rebuilding a session was slower when every materialize paid for structuredClone; the kit now skips that clone on serialize-only paths. Historical GeForce DirectML receipts remain labeled historical—not this host, not a datacenter attestation.

Workstation 0.1

The first success is local. You clone the kit, open it in your editor, and run the command sequence. FractiSI does not operate the machine.

git clone https://github.com/FractiAI/tiny-footprint-workstation.git
cd tiny-footprint-workstation
node scripts/tiny.mjs doctor
node scripts/tiny.mjs install
node scripts/tiny.mjs demo
node scripts/tiny.mjs benchmark
node scripts/tiny.mjs report
