FractiSI Multi-Agent

The Fractal Holographic Goldilocks Rhyming World Model for Digital (and Human) Agents.

FractiSI Multi-Agent is the Rhyming World Model: it registers shared context once, gives each agent only what differs, and recognizes repeat work even when the words change. It runs beside Cursor, Claude Code, VS Code, and Git — beside coding assistants, not another one of them, and not a model swap.

What the tests show

Most agent teams give every agent its own copy of the same context, then fight over the merge. FractiSI keeps one shared world and gives each agent only what is different. These are lab results, run on public data.

Results against the usual approaches

Compared with skimming, full copies per agent, compression alone, and caches that only match identical text.

Finding answers 100 of 100 vs 0

With a shared world, agents assembled every hidden chain. Skimming found none.

Speed to an answer Half the rounds

Three rounds instead of six, and 85% fewer operations, on the same search.

Agents per machine 36× to 62×

The shared world is stored once. Each agent adds only its difference.

Beyond compression 42%+ smaller still

Compressing full copies does not remove the repeated content. A shared world does.

When the wording changes 33% to 49% smaller

Real protein, GPS and agent messages. An exact-match cache never hit. Rhyming templates stored the same traffic in a third to a half less space.

Shared vs private copies 5× to 20× more accurate

Same model, four agents that each see one piece. One shared world predicts what happens next far better than private copies.

Tiny Gateway 84.5% · 81.4%

Less data held and less GPU memory allocated by the Tiny Footprint core.

Rhyming vs non-rhyming world models

Full expedition page →

Real agent work is mostly the same job in different words. A normal cache only helps when the text is identical. A rhyming world model recognizes the pattern, so it still helps when the words change. We tested both on public data and on open-source world models we ran ourselves.

SituationWithout rhymeWith rhyme
Protein notes, same structure, new wording22,261 bytes, no cache hits14,882 bytes · 33% smaller
Agent messages, same shape, new numbers136,546 bytes, no cache hits69,912 bytes · 49% smaller
Hidden-answer search, 100 cases0 found100 found
Mostly identical textExact cache and prefix reuse winKeep using them. FractiSI does.

Open-source world models such as DreamerV3, MuZero and TD-MPC2 are strong when one agent plans alone. None of them can share or merge a world between agents. That is the job FractiSI does.

On the protein task a plain shared notebook also got every answer right, so there the gain is size, not accuracy. Upstream models were trained for minutes on a laptop-class CPU, so their numbers reflect short training. Not run: V-JEPA 2-AC, Cosmos (need a GPU) and Genie (closed). Details on the expedition page.

How it works

Shared world

Policies, maps, tools, corpora, and simulation state are registered once as a shared template.

Per-agent deltas

Pose, goals, inventory, and local memory. Only what differs from the shared world.

Selective reconstruction

Nested vectors let an agent load only the scales it needs. The saving applies to the runtime working set, not only file size.

Honest limits

  • Lab figures are FractiSI architectural and structured-state measurements. They inform product decisions. They are not CapEx guarantees.
  • The stack runs as catalog and in-process labs inside Syntheverse Sandbox, on Base Mainnet as bedrock. Entering and leaving is voluntary. No crypto purchase is required.
  • Net Zero here means a balanced zero under continuous activity. It is not empty void, not climate-policy net zero, and not certified zero-watt computing.
  • Rhyme is not a prefix cache. ΦEGS and Infinite Octaves are design grammar for nesting, not physics and not measured infinite tiers.
  • Tiny Gateway (engine shelf #52) is not a production HBM proof. The hexagon–circle question is partly open.
  • This is not a Theory of Everything, not an Active Inference claim, and awareness here is not consciousness.
