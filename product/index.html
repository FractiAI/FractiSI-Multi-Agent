Tiny Footprint

The memory layer beside frontier serving. Install next to the stack you already run—not a new cluster, not a model swap.

Community is free. No account. Server and Cloud are commercial editions for fleets that need the same engine at scale. Why we stay open →

Exact prefix sharing remains the win when the same words repeat—production caches already do that. Tiny Footprint widens the bank to organizational rhyme: same structure, different wording—the near-duplicate case exact caches miss. Better utilization of the memory you already bought. Not a larger chip.

One engine · three deployment surfaces

Local

Developer machine. Community free. Developer Pro proposed at $29–49 / month. Workstation is the path: clone, demo, benchmark yourself.

Server

Company GPU fleets already serving models. Team and enterprise terms proposed from $199 / month to custom annual. Start on a test cluster.

Cloud

Platform operators. Licensing, OEM, and per-GPU-hour terms negotiated. Partner conversation—not self-serve checkout.

What independent measurement shows

Open re-measurement (Apple M4 Pro · small GPT-2-family models · PR #3) is the honesty bar for product claims. Shared prompt prefix is the mechanism that performs. Prefill can run about 1.3×–3.5× faster; KV residency can fall about 84% (about 27% with weights counted). Exact text remains the strong case; rhyme extends the near-dupe case.
