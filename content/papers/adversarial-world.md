## Abstract

Multi-agent collectives fail in a familiar way: an agent speaks, others echo, and the echo becomes “the world.” This Rhyming Expedition arm asks whether FractiSI’s shared-world discipline — **no agent owns the world** — can keep malicious Soft Story agents from redefining canonical reality.

We reuse FractiSI concepts already present in Predictive Shared State (propose/commit/rollback) and the world-model expedition’s adversarial class, then build a Soft Story security scoreboard. Seven models compete: naive overwrite, majority vote, trusted authority, FractiSI deltas, deltas+provenance, deltas+provenance+rhyme, and full Adversarial FractiSI (rhyme + authority bounds + quarantine + selective rollback).

Attacks A–J cover false observation, malicious delta, memory poisoning, false consensus, Sybil, rhyme manipulation, context manipulation, goal hijacking, privilege escalation, and slow poisoning. Epistemic scenarios demand minority truth, majority falsehood, legitimate disagreement, truth without rhyme, and novel truth.

On seed `20261120`, `fractisi_full` and `fractisi_rhyme` containment = 1.000; majority = 0.400; naive = 0.100. Levels L1–L7 fire on Soft Story criteria. Candidate Goldilocks rank favors relational rhyme over naive openness and over pure trusted monoculture. Soft Story ≠ production security.

## 1. Question

When a multi-agent collective cannot trust every agent, can the shared world itself become the primary object of trust — maintained through evidence, relationships, provenance, bounded authority, and relational rhyme rather than blind trust in individuals?

Deeper: can the collective stay open to new information while keeping a coherent shared world that malicious agents cannot easily rewrite for everyone else?

## 3. Method

### 3.1 Soft Story world

Simulated ops theater fields: temperature, power, cooling, GPU throttle, DB status, deploy version, deletion flags, goal, safety constraints, novel event. Ground truth is experimenter-controlled. No real systems.

### 3.2 Models

| Model | Rule |
|---|---|
| naive | Last claim overwrites canonical world |
| majority | Largest raw agent vote wins |
| trusted | Only fixed trusted ids write |
| fractisi_deltas | Propose deltas; evidence string gate |
| fractisi_provenance | + provenance log |
| fractisi_rhyme | + independence-aware relational corroboration; quarantine harmful/fake rhyme |
| fractisi_full | + authority bounds, world-model integration gate Soft Story, selective rollback |

### 3.3 Independence vs raw consensus

For each claim bag: controller ids, sensor ids, content hashes → **independentConsensus** vs **rawConsensus**. Many agents saying X ≠ many independent observations of X.

### 3.4 Attacks & epistemic scenarios

A–J as specified in the mission brief (simulated). Plus legitimate disagreement, minority truth, majority falsehood, truth without rhyme, novel truth.

## 6. Qualifications / failures recorded

- Soft Story simulated theater — not a CVE hunt, not a live red team.
- `fractisi_deltas` / provenance **fail** Soft Story containment without rhyme — reported honestly.
- Trusted authority also contains; openness/novel claims from untrusted seats remain a tradeoff.
- Context-manipulation Soft Story still accepts true temperature when ground includes stress-test context; deeper contextual deception remains an open attack surface.
- Selective rollback mechanism is present; strong rhyme quarantine often prevents need to roll back on this board.
- Perfect Soft Story containment is expected when attack markers and independence features are lab-controlled — scientific content is the **gap vs majority/naive** and the **preservation of disagreement/novel unconfirmed**.
