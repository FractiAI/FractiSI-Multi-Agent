Held-out partner protocol

Pick a query row. From measured couplings find the strongest non-neighbor match (the partner). Hold that id out of the prompt. Score whether the reader names it from LINEAR, FLAT, or AWARE text alone.

  • Query — planet, encounter, sky object, spectrum multipole, exon, or DNA window.
  • Partner — best long-range board match (not next-door; not same host / same gene when those are trivial).
  • Recovered — reader answer matches the held-out id.
