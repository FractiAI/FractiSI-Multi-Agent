How to read the nested map in one breath

Protein folding says: line of parts → relationship board → long-range partner. The LLM rhyme says: write that as a local paragraph, as a dump, or as a ranked board for a language reader. Cosmos and genome each sit inside both stories. That is what “nested rhymes” means here — not that planets are amino acids, and not that DNA is a chatbot.

What “held-out partner” means (follow along here)

We pick one row (the query). From measured relationship numbers we find who it couples with most strongly that is not among its nearest neighbors in the list (the partner). Then we hold that name out: we do not print “the answer is X” in the prompt. We only give the query plus one of three ways of writing the room. The test asks: can a careful reader still name that hidden partner?

  • Query — the row we start from (planet, encounter, sky object, spectrum multipole, exon, DNA window).
  • Partner — the best long-range match from the measured board (not a next-door neighbor; not the same host star / same gene when those are too easy).
  • Held out — the partner’s id is the answer key for scoring; it is not handed to the reader as a labeled solution. “Recovered” means the reader’s answer matches that id.

Example: start from planet A. The board says planet Q is the strongest non-neighbor match. Hide Q. Give the reader nearby planets in order (LINEAR), a messy pile (FLAT), or a ranked “strongest links” list with a leading candidate (AWARE). Did they name Q? That yes/no is one task.

What we observed (plain language)

  • Observation 1 · Cosmic language packs On NASA exoplanets, JPL close approaches, OpenNGC deep-sky objects, and the WMAP microwave spectrum, we asked the same question in three prompt styles. The ranked “AWARE” pack named the hidden (held-out) partner 100% of the time (48 tasks per layer). The local-window “LINEAR” pack and the unsorted “FLAT” dump recovered about 0%.
  • Observation 2 · Human-genome demo packs On a public exon panel and on sliding windows of human mitochondrial DNA, the same three packs showed the same shape: AWARE 100%, LINEAR ~0%, FLAT near zero (14 long-range exon tasks; 64 chrM window tasks).
  • Observation 3 · The win is the map in the pack When a reader ignored the ranked board and only matched overlapping words, AWARE fell to about 0%. So the result is not “lucky word overlap.” It is the relationship map written into the prompt.

How novel is that?

  1. Highest novelty here (named discoveries). AWARE packs list concrete partners and couplings per theater — not only a 0% → 100% pass rate — on public sky files and a public genome panel.
  2. Moderate novelty (demonstration). The genome arm is a careful demo on small public panels. Same packing shape. Not a disease finding. Not clinical. Not wet-lab genetics.
  3. Residual physics lives elsewhere. Cosmic Rhyme reports two candidates for new physics (WMAP residual lags 11 and 14) as a secondary finding. This LLM note explores the language-pack rhyme and does not own that residual sieve.
  4. Not a frontier-model contest. Default score uses a pack-compliant reader (no API key). That proves the rhyme lives in the pack. A live commercial model is optional follow-up, not this receipt.
