# Tiny Gateway · Rhyming Templates

Architectural memory lab for Rhyming Templates, nested vectors, eight-node shared broadcast, and selective reconstruction. **80% resident-representation reduction** is the research target; the engine pin is gated on representation bytes plus the GPU proxy lab. DRAM is the product analogue, not a quantity measured here.

```bash
# from this suite directory:
npm run research

# from the workstation repo root:
cd research/synthobs-tiny-gateway-rhyming-templates && npm run research
```
