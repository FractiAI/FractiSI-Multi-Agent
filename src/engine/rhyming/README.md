# Rhyming templates

A rhyme is the same fields holding the same kinds of values, recursively. The catalog stores and routes templates by structural signature, the codec turns an expression into a reference plus a nested delta, and the gate audits four pillars.

## Contents

| Path | What it is |
|---|---|
| [`catalog.mjs`](catalog.mjs) | Rhyming Template catalog: patterns frozen on registration, indexed by structural signature, and routed by signature bucket with a `shapesRhyme` confirmation. |
| [`codec.mjs`](codec.mjs) | Expression codec: an expression is a template reference plus a nested field-level delta, with optional separate state. |
| [`gate.mjs`](gate.mjs) | Holographic rhyme gate for Rhyming Templates. |
| [`index.mjs`](index.mjs) | Re-exports this folder's public API. |
| [`route.mjs`](route.mjs) | Geometric / structural rhyme routing — signature buckets + scored partials. |
| [`shape.mjs`](shape.mjs) | Shape comparison for Rhyming Templates. |
