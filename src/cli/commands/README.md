# Commands

One module per command.

## Contents

| Path | What it is |
|---|---|
| [`benchmark.mjs`](benchmark.mjs) | Benchmark this machine. |
| [`demo.mjs`](demo.mjs) | Run the multi-session reference workload and print its byte comparison. |
| [`doctor.mjs`](doctor.mjs) | Report the workstation, its optional toolchain, and any accelerator present. |
| [`install.mjs`](install.mjs) | Verify the kit is present and ready. |
| [`integrate.mjs`](integrate.mjs) | Show the versioned adapters; integration never replaces the customer's stack. |
| [`join.mjs`](join.mjs) | Join the validation initiative. |
| [`report.mjs`](report.mjs) | Write the HTML report and, only on request, share it. |
| [`share.mjs`](share.mjs) | Send the latest results to the validation desk, after confirmation. |
