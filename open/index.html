Open source

Why we stay open

If a stranger cannot run it, refute it, or fork it, we do not get to treat the claim as settled.

Closed labs can be wrong for years

Work aimed at more capable AI attracts secrecy. We take the opposite bet. A closed stack can move fast and still be wrong for a long time. Public code and runnable receipts are slower on the press release and faster on correction. That is the point of opening Tiny Footprint and the research behind it.

Falsifiability is the product of openness

A skeptic with a laptop should clone the Workstation, run the same comparison, and disagree with us using the same instruments. If only we can reproduce the result, it is not ready to sell as settled. Openness without that bar is advertising.

Free to verify · paid when it earns the seat

Community Workstation is free. The repositories and papers are public. Developer Pro, Server, and Cloud are how the company pays people who keep the product alive. You verify without buying. You buy when the software earns a place beside your fleet—not because the truth was locked behind a login.

How to verify

Clone tiny-footprint-workstation. Run doctor → install → demo → benchmark → report. Read the paper in the library. You should get a reproducible comparison without FractiSI operating your box.
