A Protein-Folding Telescope for the Cosmos

What becomes visible when cosmic observations are held as relationships rather than as a sequence of measurements?

FractiSI · Companion paper: Cosmic Rhyme Expedition · Bridge: Protein Folding as a Rhyme for Intelligence

Read the expedition paper Receipts Test Drive

We named this carefully. Cosmos, not Universe. The distinction matters. We are not claiming a story about the totality of existence. We are asking what the observable layer — catalogs, spectra, close approaches, deep-sky objects — looks like when you stop reading it as a list and start holding it as a set of relationships.

That question is the next arm of a rhyme we already tested elsewhere. In proteins, a linear sequence hides long-range contacts that a coupling board can recover. In knowledge work, supporting titles hide in passage relationships. In macro series, teleconnections hide in lagged couplings. Collaboration surplus shows up when parts are complementary. The grammar is the same: LINEAR, FLAT, AWARE. The open question for this expedition was whether that grammar still earns its keep when the material is the sky.

The experiment

We loaded public fixtures anyone can regenerate: NASA’s confirmed exoplanet table, JPL’s close-approach file for near-Earth objects, OpenNGC’s deep-sky catalog, and the WMAP nine-year temperature spectrum. We did not tell the pipeline to find filaments, voids, or dark-matter maps. Those names are known structure. We asked for something harder and cleaner: recurring relational motifs that cross objects or observables, then survive held-out data and null tests that scramble the features.

For each catalog we compared three organizations of the same material. LINEAR sees a local window along right ascension or time. FLAT sees an unstructured dump. AWARE sees an explicit board of measured couplings. The scored job on C1 was exact recovery of a held-out long-range partner. On C3 the same job ran on multipoles. On C2 the pipeline proposed motifs and the cosmic held-out split, plus feature-permutation nulls, decided which ones lived.

Hypothesis

If relational awareness is a general property of intelligence, then increasing the relational representation of cosmic data should expose structure that is difficult to recover from the same data represented linearly. The model may propose. The data must decide.

What came back

On every catalog layer we tried, the relational board recovered partners the linear window and the flat dump missed. Exoplanets, NEO encounters, and OpenNGC long-range tasks went from effectively zero under LINEAR/FLAT to full recovery under AWARE on the held-out long-range slice. The WMAP temperature spectrum showed the same shape: a lag-coupling board finds multipole partners a local multipole window does not. That is the folding rhyme, now pointed at the sky.

The open motif search returned eight signatures that survived false-discovery control and held-out replication after we banned tautological feature pairs. Two of the strongest exoplanet survivors couple discovery year to stellar radius and stellar temperature. That is not a new law of planets. It is a survey-history super-pattern: when you hold the catalog as relationships, you can see how the era of discovery lines up with the kinds of host stars the instruments were finding. Several OpenNGC survivors couple apparent size to sky position and brightness. The honest audit calls those selection and morphology candidates, not detections of the cosmic web by name — because we never aimed the telescope at those names.

Qualifications

AWARE wins on C1 and C3 because it is allowed to use a ranked relational map built from the same features LINEAR never ranks. That is the same honesty rail we used on proteins and macro series. It is a representation result. It is not a claim that the software invented new physics, mapped dark matter, or explained the Universe. Motifs that look like selection effects stay labeled as selection effects. Trivial near-duplicate features were filtered before scoring so distance-min versus distance did not count as a discovery.

Why the framework still earns a seat

A telescope is useful when it changes what you can see without lying about the optics. This one is a protein-folding telescope: sequence to couplings to fold, applied to observations to relationships to whatever structure the held-out sky will defend. Rent and research budgets both care whether a method generalizes past the demo that made it famous. Here the method generalized to four public cosmic layers, and the open search produced catalog-level patterns you can argue with — which is the point. The receipts are regenerable. If a motif fails on your machine, it fails.

Invitation

Read the paper, run the suite, and disagree with the audit labels if you have a sharper one. The next useful argument is not whether relationships matter in the abstract. It is which cosmic motifs survive when someone else holds the same public files.
