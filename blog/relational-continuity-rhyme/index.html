Short answer: Yes. Rhyme accuracy 1.0 across partners, question↔answer, agent worlds, and seed↔edge at depth 8. Exact cache 0. Lexical similarity ≤0.14. Removing rhyme drops partners to 0.083. ENGINE_SHELF pin deferred.

Shared-World work already showed rhyme beats exact caches when wording changes. This arm asks whether the same operation covers the full progression teams meet in the field: who belongs with whom, which answer closes which gap, and whether a seed still relates to a far edge after many rewrites.

What we measured

Five levels, one structural definition of rhyme. Arms: exact cache, token-Jaccard similarity, shared bag without a relational index, FractiSI minus rhyme, FractiSI rhyme. Question–answer trials use distractors that look like the question but miss the world gap. Seed↔edge octaves strip inherited seed text so ordinary propagation cannot cheat.

Results

  • Partners: rhyme 1.0 vs embedding 0.14
  • QA: rhyme 1.0; lexical trap wins 0/120
  • Seed↔edge (depth 8): rhyme 1.0; embedding/exact 0 without inherited text
  • Ablation: full 1.0 · minus_rhyme 0.083
