Why this symposium

The symposium brings together people who treat agents as systems that must keep a grip on a changing world, not as chat sessions that answer one prompt at a time. We position FractiSI Multi-Agent as a possible rhyme with Active Inference. Humans are agents too. They work in a shared world alongside software agents, each with different observations, beliefs, and actions. By rhyme we mean a structural kinship worth testing together. We do not claim the two frameworks are the same. Throughout the Test Drive, human and digital agents collaborate in one shared world.

Our side of the question is computational architecture. How do many specialized participants, human and machine, share one underlying project without each reconstructing an overlapping copy of it? As fleets grow, the cost is easy to miss. Agents reprint context. Exact-text caches help only when the words match. Gzip shrinks each copy but does not remove the cost across copies. At merge time, coordination becomes a negotiation among divergent private worlds. Teams see it as slower coordination, fewer agents on the same hardware, and more reconciliation before anyone can trust a composed result.

FractiSI Multi-Agent gives them one shared computational world, many specialized participants including human operators, coordinated work, and composed results. Tiny Footprint, powered by Tiny Gateway, keeps the shared world compact. The platform surfaces above it (Coordination, Shared state, Composition, Git awareness, Deploy) sit beside Cursor, Claude Code, VS Code, and Git. It is not a coding assistant. It is a coordination layer for agentic engineering.

Opening remarks

On November 12–13, 2026 we give a six-minute opening: short remarks and an invitation into the work, not a 30-minute lecture.

FractiSI Multi-Agent: One Shared World. Many Agents. Coordinated Work. Composed Results.
A Shared-World Architecture for Multi-Agent Intelligence.

The remarks name the problem of duplicated worlds, point at the architecture, and invite Active Inference researchers to run joint experiments without treating the frameworks as interchangeable. The depth lives in what the audience can run next.

The Test Drive

The invitation is to a self-paced Test Drive. It follows one arc with the deck: the question, a short story about awareness, Syntheverse Sandbox on Base Mainnet, the problems with many agents, Net Zero and rhyme, six live tests, the stack, and a prediction layer agents can rehearse before touching the real world. It ends with ways to join the beta. Run each test in the browser, or in an IDE with testdrive N. It needs no account and no wallet. Deploy is paid.

A parallel Musical Training Program follows the same conceptual journey across 16 Bach-inspired cello chapters. The training is also a playlist on Suno AI — listen on Suno — so the invitation includes both the runnable Test Drive and a musical path through the same ideas.

What we want from the conversation

We want fair comparisons. A memory saving that slows work or hurts accuracy is not a win. A shared substrate that becomes a bottleneck, erases private agent context, or cannot represent disagreement is not a finished architecture. The opening states those questions in public because they are the work; the Test Drive lets you measure them yourself.

If you work on Active Inference, multi-agent systems, or agent infrastructure, we would rather compare instruments than trade slogans. Join open evaluation, clone the kit, or write to us after the session. If the architecture is useful, it will hold up on other people's workloads. If it is not, we would rather find out with you.
