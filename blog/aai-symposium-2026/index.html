Why this symposium

The symposium brings together people who treat agents as systems that must keep a grip on a changing world, not as chat sessions that answer one prompt at a time. We position FractiSI Multi-Agent as a possible rhyme with Active Inference. Humans are agents too. They work in a shared world alongside software agents, each with different observations, beliefs, and actions. By rhyme we mean a structural kinship worth testing together. We do not claim the two frameworks are the same.

Our side of the question is computational architecture. How do many specialized participants, human and machine, share one underlying project without each reconstructing an overlapping copy of it? As fleets grow, the cost is easy to miss. Agents reprint context. Exact-text caches help only when the words match. Gzip shrinks each copy but does not remove the cost across copies. At merge time, coordination becomes a negotiation among divergent private worlds. Teams see it as slower coordination, fewer agents on the same hardware, and more reconciliation before anyone can trust a composed result.

FractiSI Multi-Agent gives them one shared computational world, many specialized participants including human operators, coordinated work, and composed results. Tiny Footprint, powered by Tiny Gateway, keeps the shared world compact. The platform surfaces above it (Coordination, Shared state, Composition, Git awareness, Deploy) sit beside Cursor, Claude Code, VS Code, and Git. It is not a coding assistant. It is a coordination layer for agentic engineering.

The talk

On November 12–13, 2026 we give a 30-minute talk:

FractiSI Multi-Agent: One Shared World. Many Agents. Coordinated Work. Composed Results.
A Shared-World Architecture for Multi-Agent Intelligence.

It covers the problem of duplicated worlds, the architecture, why density and collective outcomes matter more than smaller data alone, and what a fair experimental comparison should measure. It sketches applications in software engineering and in air-traffic and defense coordination, which we name as areas for investigation and not as solved problems. It closes with an invitation to Active Inference researchers to run joint experiments without treating the frameworks as interchangeable.

The deck includes speaker notes, keyboard navigation, and print or PDF export. Links on the slides open product pages, papers, and runnable commands in a new tab.

The Test Drive

The Test Drive and the deck follow one arc. It opens with the question, then a short story about awareness, then where it all runs: Syntheverse Sandbox on Base Mainnet. Next come the problems with many agents and two definitions, Net Zero and rhyme. Then four live tests, a tour of the stack, and a layer we are adding that lets agents rehearse a change before it touches the real world. It ends with ways to join the beta. Run each test in the browser, or in an IDE with testdrive N. It needs no account and no wallet. Deploy is paid.

What we want from the conversation

We want fair comparisons. A memory saving that slows work or hurts accuracy is not a win. A shared substrate that becomes a bottleneck, erases private agent context, or cannot represent disagreement is not a finished architecture. The talk states those questions in public because they are the work.

If you work on Active Inference, multi-agent systems, or agent infrastructure, we would rather compare instruments than trade slogans. Join open evaluation, clone the kit, or write to us after the session. If the architecture is useful, it will hold up on other people's workloads. If it is not, we would rather find out with you.
