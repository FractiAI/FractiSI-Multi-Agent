Upgrade the World Model, Not the Org Chart

Capable agents, human and digital, are limited less by their own ability than by the world model they coordinate through. We tested a shared-world alternative on real public data.

FractiSI · Companion paper: Upgrading the World Model

Read the paper Test Drive Expedition 002

Most multi-agent systems still follow one pattern: an agent receives a role, a rule, and a plan, then passes messages along a chain toward an objective. It is predictable and it scales to a point. It also puts a ceiling on capable agents. They stop being able to find relationships nobody planned for, each one carries its own private copy of the context, and the cost of keeping those copies in agreement grows with every agent you add.

Two world models

We call the standard pattern the Legacy Linear world model. Information moves agent to agent, authority follows the hierarchy, and coordination is whatever the plan says it is.

The alternative is a Fractal Holographic Goldilocks world model. Agents work inside one shared world. Each holds only its own differences from that world, and anything else is reconstructed on demand. Boundaries and consent decide who sees what. The target is a band with enough structure to stay coherent and safe, and enough freedom for agents to use the capability they have.

What we measured

FractiSI Multi-Agent is the computational lab. The suite runs six experiments (E0 to E5), regenerated from a fixed seed on public data and on our own prior receipts.

Shared worlds cut redundancy without costing accuracy. Against a competition-first setup, a shared world reduced duplicated bytes by about 91% with identical accuracy. Selective sharing between a closed and an open configuration cut bytes by about 87% at matched error. Expedition 002, which we cite rather than rerun, showed guided reconstruction solving a six-hop discovery board that flat skimming never solved, in about half the coordination rounds.

Order carries information. On 805 walk-forward windows of the FRED unemployment series, a model that respects time order scored an RMSE of 5.675 against 6.115 when the sequence was permuted. A bag-of-features baseline was almost tied with the temporal model (5.673), so we do not claim temporal structure is the winner there. On Movebank animal tracks aligned with the Kp geomagnetic index, lag-1 structure was about 0.34 against about 0.04 for the shuffled null.

A scoreboard, with caveats. We scored four world models on capability, safety, cost, sustainability, and participation quality, using the dimensions the suite measured. The Goldilocks configuration came out ahead at 76.5, against 75 for unbounded openness, 71 for competition-first, and 66.5 for control-first. The margin over unbounded openness is small and the weights are ours, so read it as a lab scoreboard, not a verdict.

Where this goes

The same question applies to any organization building on accelerated computing, from chips through models to agent fleets and the teams around them. The first step is an audit, not a reorganization: how agents are defined, how the world is represented, where context is duplicated, how dense the agent population is, where boundaries sit, and where flow stalls. The goal is to locate the mismatch between the world model in use and the capability already present.

Reject or revise the approach if shared worlds show no advantage, if added autonomy hurts results, if consent-based coordination loses to central control, or if migration adds complexity without a safer, cheaper, or more usable system.

The next decisive experiment is the one we have not run: the same models, prompts, tools, and budgets, with only the information architecture changed. You can run the labs yourself in the Test Drive or clone the kit.
