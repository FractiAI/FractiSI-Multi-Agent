Can published DNMT3A tools that edit APP count as new wiring? Yes. STRING shows no APP–DNMT3A edge while its live control INS↔POMC scores 0.947. Rhyme coupling is about 0.745, and three wet-lab roles pass. The wiring is built from existing dCas9-DNMT3A work, not a new assay.

That distinction matters for translational teams drowning in literature. A wire filed from published roles under an empty-interaction gate is triage organization, not a claim that someone just ran a brand-new physical experiment. The empty STRING gate and the live control score travel with the claim so the filing cannot be mistaken for unfinished biology dressed as discovery.

The headline is therefore yes with a boundary: published tools can mint a wire when roles assemble cleanly and the interaction catalog stays empty, provided the control score sits next to the couple.

Wiring discovery can assemble published roles under empty-interaction gates without claiming a brand-new experiment. The move is organizational. Take tools that already edit APP through DNMT3A machinery, check that the live interaction catalog does not already list the pair, confirm a known control edge still scores high, and measure rhyme coupling across the assembled roles.

When those pieces clear, the edge can be filed as literature-built wiring. When they do not, the candidate stays quiet. The method does not replace kill tests where biology still needs a new assay. It expands the triage set from work that already exists in the public record.

APP and DNMT3A are a clean case for that rule. The catalog is empty for the pair. The control is live. The coupling clears. Three published wet-lab roles pass. The discovery is the assembly under gates — not a new pipette day.

Translational teams can file literature-built wires as triage while funding follow-up where needed. That split saves time. Edges that already clear empty gates and role assembly move into the queue; edges that still need a new assay stay marked as open lab work instead of being smuggled in as finished discovery.

Buyers and reviewers should insist on the same honesty rail in every literature-built filing: empty-gate status, control score, and coupling figure in one place. If any of those pieces is missing, treat the wire as unfinished organization, not as a translational conclusion. The APP–DNMT3A case shows how that rail looks when it is intact.
