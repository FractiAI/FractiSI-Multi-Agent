Short answer: This is a matched FractiSI vs no-kit ablation. Same frozen payloads in-clock; FractiSI records tasks 4 / contributions 4 / compositions 1; no-kit 0/0/0. Mean ~1.29 s vs ~10.8 s over five runs. RH remains OPEN.

Matched trial

Same frozen Lean payload bytes. Two arms. Work inside the clock. Hard gate on both.

What each arm does

  • No-kit — sequential write of four modules, then lake build + forbidden-token scan
  • FractiSI — four agents claim tasks, submit contributions, compose, git-integrate, then the same hard gate

Measured (5 runs)

  • No-kit mean 1.29 s · FractiSI mean 10.8 s (coordination path overhead on this workload)
  • FractiSI every run: tasks 4, contributions 4, compositions 1
  • No-kit every run: 0 / 0 / 0
  • Both arms hard-gate green ×5

What this is not

Not LLM proof search. Not a 30 h vs 5.3 s efficiency claim (that lead stays withdrawn). Not a proof of RH — status remains OPEN.

Reproduce

cd expeditions/riemann-fractisi/lean && node timing/run-ablation.mjs
