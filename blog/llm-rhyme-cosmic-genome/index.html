When You Pack the Sky and the Genome as Language, Does the Folding Rhyme Still Show Up?

We split the language-pack rhyme out of Cosmic Rhyme and aimed it at public sky catalogs plus a human-genome demonstration panel — with an explicit legend that maps each file to LINEAR / FLAT / AWARE the way a folding map legends a trail.

Paper (with full tables): LLM Rhyme Expedition · Sibling: Cosmic Rhyme (C1–C4)

Read the paper + legend tables Receipts

Bottom line

Under a pack-compliant reader, AWARE packs hit 100% on four cosmic layers and on both genome layers, while LINEAR/FLAT stay near zero. Lexical-blind reading that ignores the board fails. Not a frontier bake-off. Not wet-lab genetics. Not clinical advice.

Legend · one line

Protein : MSA board : contact = Knowledge : title board : title pair = Macro : lag board : teleconnection = Cosmic : AWARE pack : partner id = Genome : AWARE pack : partner id.

What happened on the receipt

Cosmic exo / NEO / NGC / WMAP: 48 tasks each · LINEAR 0% · FLAT 0% · AWARE 100%. Genome exons: 125 objects, 14 long-range cross-gene tasks · AWARE 100%. chrM windows: 275 objects, 64 tasks · AWARE 100%. Lexical-blind AWARE ≈ 0% — the win is the map in the pack.

Why the legend matters

Without a legend, “LLM rhyme” sounds like poetry. With a legend, anyone can see that a NASA planet row plays the same role as a protein residue, a JPL encounter plays the same role as a knowledge title, and a chrM window plays the same role as a lag-coupled macro series — different public files, same packing grammar. The full paper keeps the larger domain-bridge table and methods.
