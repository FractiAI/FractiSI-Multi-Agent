What ranked packs named

Ranked relationship packs recovered partners that local windows and unsorted dumps missed, and catalogued them per theater:

  • Exoplanets — HAT-P-8 b ↔ WASP-7 b · HD 62509 b ↔ HD 11977 b · TrES-3 b ↔ CoRoT-2 b
  • Near-Earth objects — 2012 XL16 ↔ 2015 KS120 · 2015 AB45 ↔ 2015 BC515
  • OpenNGC — IC0069 ↔ IC0096 · IC0058 ↔ IC0036
  • WMAP temperature spectrum — multipole partners under the leading lag; board lags 5 / 1 / 11
  • Genome exons — NPY↔SOD1 · INS↔POMC · APP↔DYRK1A (demo panels)
  • Mitochondrial windows — for example chrM:1860–1980 ↔ chrM:2100–2220

Nested map in plain English

Read left to right: public file → protein-fold nest → language-pack nest → partner to recover. For NASA exoplanets, JPL close approaches, OpenNGC objects, and WMAP multipoles, the protein-fold nest turns a catalog row into a relationship board whose long-range contact is the partner; the language nest writes that board as local neighbors, an unsorted dump, or a ranked pack with a leading candidate. For public exons and mitochondrial DNA windows, the same shape applies across genes or windows — same-gene or next-door matches count as trivial.

Held-out partner protocol

Pick a query row. From measured couplings find the strongest non-neighbor match (the partner). Hold that identity out of the prompt. Score whether the reader names it from local, dump, or ranked text alone.

  • Query — planet, encounter, sky object, spectrum multipole, exon, or DNA window.
  • Partner — best long-range board match (not next-door; not same host or same gene when those are trivial).
  • Recovered — reader answer matches the held-out identity.

What we observed

  • Cosmic language packs. On NASA exoplanets, JPL close approaches, OpenNGC, and WMAP temperature spectrum: ranked packs named the held-out partner 100 percent (48 tasks per layer). Local and dump packs recovered about 0 percent.
  • Human-genome demo packs. Public exon panel and mitochondrial windows: ranked packs 100 percent, local about 0 percent, dump near zero (14 long-range exon tasks; 64 mitochondrial window tasks). Demo panels only — not clinical.
  • The win is the map in the pack. When a reader ignored the ranked board and only matched overlapping words, ranked recovery fell to about 0 percent. The result is the relationship map written into the prompt, not lucky word overlap.

Novelty and boundaries

  1. Highest novelty here. Named partners and couplings per theater on public sky files and a public genome panel — not only a 0 percent to 100 percent gate.
  2. Moderate novelty. Genome arm is a careful demo on small public panels. Same packing shape. Not disease. Not clinical. Not wet-lab genetics.
  3. Residual physics lives elsewhere. Cosmic Rhyme’s two candidates for new physics (WMAP residual lags 11 and 14) are secondary and not owned by this language note.
  4. Not a frontier-model contest. Default score uses a pack-compliant reader. A live commercial model is optional follow-up, not this receipt.
