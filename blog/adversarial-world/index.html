Can Relational Rhyme Detect and Contain Malicious Agents in a Shared World?

Relational fingerprints vs disease labels on a regenerable Soft Story pan-cancer board — compression, transfer, and honest null qualification.

Short answer: Yes. On twenty-four Soft Story cancer worlds labeled with public TCGA project names, entity-invariant relational fingerprints predicted phenotype at 1.0 while disease-identity transfer scored 0 and relation bags scored about 0.46. Six rediscovered structural motifs covered what twenty-four labels described (×4 compression). Cross-cancer transfer reached 0.8. Null span recurrence remains inconclusive. Disease labels organize clinics; they transfer poorly when the question is whether a resistance pattern in one tissue can warn another. This Rhyming Expedition arm withholds Hallmarks from discovery, builds shared worlds first, and asks whether recurring relational shapes compress the catalog.

What we measured

Models A (disease identity), B (relation bags), and C (entity-invariant rhyme fingerprints) on the same regenerable board. Leave-one-out phenotype prediction, rhyme compression, cross-cancer transfer, shuffled null worlds, and local-versus-shared divergence proxies.

Results

  • Model C phenotype 1.0 · Model B ~0.46 · Model A 0
  • Compression: 24 disease labels → 6 strong planted rhymes (×4)
  • Cross-cancer transfer 0.8 vs disease-identity baseline 0
  • Local−shared divergence higher on malignant-like Soft Story phenotypes
  • Null span test inconclusive — report phenotype/transfer, not span exclusivity
